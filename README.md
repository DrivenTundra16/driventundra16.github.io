# kyomufs.github.io

Personal site: about, skills, projects and contacts.
Plain HTML, CSS and JavaScript — no build step, served by GitHub Pages from `main`.

- `index.html` — markup and copy
- `assets/style.css` — design tokens, dark/light themes, layout
- `assets/app.js` — RU/EN switch, theme switch, skills and projects rendering

Language and theme are stored in `localStorage` (`kyomufs.lang`, `kyomufs.theme`).
